# RECOIL

A top-down co-op PvE arena shooter where you have no movement keys — you move by the recoil of your own gunfire. Survive escalating enemy waves, pick upgrades, unlock weapons.

> Status: pre-development. See the design plan in the conversation.

## Stack

- Node.js + `ws` (WebSocket server)
- Plain HTML/CSS/JS + Canvas 2D (no build step)

## Setup (coming soon)

```
npm install
npm start
```
